# Assamese Data Sources

Source-level tracking (one line per site or document collection). Per-item
detail (pages, word counts, timestamps) lives in `COLLECTION_LOG.md`. This
file is folded into the root-level `report/SOURCES.md`.

**Directory layout:** every script writes the original unfiltered extracted
text to `raw/<source>/` and `clean_text()`'s output (purity filter plus the
ৰ/ৱ Assamese-vs-Bengali heuristic) to the parallel `clean/<source>/` tree,
same filenames. OCR and the original Wikipedia extraction predate this split
and only have clean-only output; not reconstructed, see note in
`COLLECTION_LOG.md`. Everything added since (scrape onward) has a true
raw and clean pair.

*Last updated: 2026-08-20, ~19:20. Token totals in `report/SOURCES.md` are
from `report/token_progress.md`'s latest rescan; a fresher rescan will update
that file independently as collection continues.*

## Manual collection, complete

- **`docs/assamese/books/`** (SCERT/NCERT Assamese-medium textbooks, Class IX-X, 29 PDFs). OCR complete, 4627/4627 pages, 100% via Tesseract `ben` fallback (no page had a usable Unicode text layer, confirmed real body text rather than watermarks, just non-Unicode legacy glyph fonts or scans throughout). No further OCR volume is available from currently-sourced material; more would need new book PDFs, a sourcing task not a pipeline one.
- **as.wikipedia.org.** Dump-based extraction, own preprocessing (counts as manual per course guidance). Complete: 25,110 articles, raw about 10.79M words, clean about 10.30M words, 0 suspect-language exclusions.
- **as.wikisource.org.** Same dump-based logic, proofread public-domain literary and document text. Complete: 403 pages written, about 222K words, 1 suspect-language page excluded.
- **xobdo.org.** First online Assamese dictionary (established 2006), wiki-based and community-edited, live-scraped with in-house preprocessing. Complete: 47,972 dictionary entries, raw about 523K words, clean about 476K words.
- **as.wikiquote.org.** Dump-based extraction, same approach as the Wikipedia and Wikisource dumps above. Complete: 1,729 pages, about 437K words.

## Manual collection, in progress this session

- **niyomiyabarta.com.** Assamese news site, sitemap-driven scrape. Running as an open-ended loop. Large catalog, about 34,000 articles discovered, well over 8M words collected so far, with non-Assamese lines dropped by the purity filter as it goes.
- **asomiyapratidin.in.** Assamese news site, sitemap-driven. Its current sitemap window is mostly drained, small trickle of new ones as they publish. Dual raw and clean writes apply.
- **assamese.sentinelassam.com.** Assamese news site (the Sentinel's Assamese edition), sitemap-driven scrape, same plain article-tag extraction as niyomiyabarta. Large catalog, about 17,000 articles. In progress. Note: a checkpoint bug found and fixed this session (three sources running as separate processes were sharing one state file section and overwriting each other's progress record) caused this source's progress counter to reset partway through. The already-collected text on disk was not lost, but the script is currently re-fetching some already-collected articles before it reaches new ones again; the corpus-wide duplicate check removes the repeated copies when the final token count is computed.
- **dy365live.com.** Assamese news channel's website. Same plain article-tag extraction as niyomiyabarta. Added this session. Its own news sitemap only exposes a recent window of articles rather than a deep archive, so it has mostly caught up to what is currently available; new articles trickle in as they publish. Same checkpoint bug as sentinelassam above affected this source too, already fixed.
- **assam.news18.com.** Network18's Assamese edition. Added this session. The article body is not in a plain HTML tag, it ships as JSON inside a `__NEXT_DATA__` script tag, so a dedicated extractor was written for it. Grew well past the initial ~40-article check: 4,522 articles processed as of 2026-08-20, ~1.44M words. Was also found this same day to be missing from `token_tracker.py`'s `SOURCES` list (a real bug, not just this doc being stale) — fixed, see `report/phase1_dataset_statistics.md`'s vocabulary-choice section for the full note.
- **dainandinbartagroup.in (Dainandin Barta).** Established Assamese newspaper group, sitemap-driven scrape, plain article-tag extraction. Found via firecrawl search this session. In progress, large catalog (22,000+ articles), running well past 10,000 collected.
- **assam.nenow.in (Northeast Now).** Assamese edition of a Northeast India news site. Content sits in `div.entry-content`, not a plain `<article>` tag (that selector was silently matching a reused excerpt widget, not the real body, caught before deploying). Found via firecrawl search this session. In progress, large catalog (60,000+ articles), running well past 14,000 collected.
- **saneki.in.** Weekly Assamese digital literary magazine, poetry and essays. A different register than pure news, useful for the spec's "natural phrasing" quality bar. Plain article-tag extraction. Found via firecrawl search this session. In progress, well past 11,000 collected.
- **YouTube auto-generated Assamese captions.** Machine transcription (YouTube's own speech-to-text), not human transcription, a different tier from OCR or scrape but still real: spot-checked this session and confirmed the text is coherent, natural Assamese, not garbled translation, even though the videos' own language metadata is often mislabeled as Hindi, Bengali, or English. Three long-form podcast and documentary channels added: aboyobbhuyan (253 videos), JSSUnsscripted (1,055 videos), and Unfiltered with Krishnakshi (296 videos). All three are early in collection and were paused partway through this session. A known ASR stutter artifact (a word repeated several times in a row) is filtered out before counting. The same checkpoint bug described above affected aboyobbhuyan specifically before being fixed. Also was missing from `token_tracker.py`'s `SOURCES` list until 2026-08-20 (a real counting bug, fixed the same day, ~53K words affected).
- **as.vikaspedia.in.** Government of India (C-DAC/MeitY) multilingual public-policy portal, same shape as the Hindi copy (own JSON extraction, sitemap discovery). Added this session. Running as an open-ended loop. 2334 URLs attempted, 1447 real articles extracted. Same slug-collision bug as the Hindi copy was found and fixed here too (hash suffix added to filenames for uniqueness).
- **jibonorshongram.in, ebook listing.** Wayback Machine snapshot of an Assamese e-book listing (live site is down), about 100 novels and poetry titles by named authors, Google Drive-hosted PDFs. **Real copyright exposure, accepted by explicit user decision**: the site's own disclaimer states these are third-party works republished without confirmed permission. Must be described accurately in the report as a third-party aggregator, not a licensed publisher. Added this session. Running, 26/78 books fully finished as of this update, checkpointed per page (not per book), so an interrupted book resumes mid-page rather than restarting.
- **Digital Library of India, Assamese books (archive.org, `collection:digitallibraryindia AND language:asm`).** 2,179 real Assamese-language books, novels, poetry, dictionaries, and textbooks, 1849 to 2015, scanned and OCR'd by archive.org itself (Tesseract, on upload). No PDF download or local OCR needed, the script fetches the ready-made `_djvu.txt` derivative directly. Added this session. The strongest source found this session: smoke test yielded 418K words from 4 items (one alone, "Sri Guru Charitamrita," was 324,860 words). A real bug was found and fixed (some archive.org filenames contain spaces and were not URL-encoded before the download request, causing a hard failure; fixed with `urllib.parse.quote`). Promoted to production: 116 items done, about 5.46M words, and climbing.
- **newsonair.gov.in (Akashvani, News On AIR).** Official government radio news-script PDFs for the Guwahati Assamese regional unit. Same underlying content as AIKosh's restricted "Assamese News Bulletin" dataset, but this is the live source site, open, no registration needed. Added this session. Small catalog (16 PDFs currently listed, no working pagination found), so running as an open-ended loop with a 30-minute recheck interval rather than a tight loop, since new bulletins only post about daily. 15/16 processed (one large non-bulletin PDF failed a truncated download, harmless, retries next run).
- **jibonorshongram.in, general articles (Wayback Machine).** Separate from the ebook listing above: the same domain was also a general Assamese lifestyle and blog site, and Wayback holds 2,275 other archived article URLs (recipes, short stories, general knowledge, horoscopes, government scheme updates, job alerts). Quality is mixed and category-dependent: job-alert posts are thin boilerplate (the site's own footer admits job listings are aggregated from other sources, a milder version of the same third-party-republish caveat as the ebook page), while story-category posts are real, original, full-length prose. Smoke test passed (5/5 real articles, 274 to 383 words each). Promoted to production as an open-ended loop. A minimum-word floor (30 words) plus the existing purity filter screens out the thin boilerplate posts automatically.
- **Assam Extraordinary Gazette (archive.org, `in.gazette.assam_extraordinary.*`).** 12,744 bilingual English and Assamese government gazette items, 2017 to 2026, uploaded by the National Informatics Centre. Same no-OCR-needed `_djvu.txt` approach as the DLI source above. Smoke test technically passed (no errors) but yield is weak: gazette notices are mostly English legal text with Assamese confined to the masthead, and the purity filter correctly strips the rest, about 15 to 19 real words per item. Promoted to production anyway since it is free and real, but expect a small total, likely well under 300K words even run to completion across all 12,744 items. Not a priority source, just free upside.

PDF download plus pdftotext/OCR fallback, paginated discovery across 161 listing pages. Added this session. Catalog fully exhausted: 822 items done, about 342K words, all 161 listing pages traversed. The while-loop was stopped (suspended and killed) once it started cycling with zero new items every few seconds.
- **archive.org, broader Assamese-language query** (`language:(asm)`, 15,385 items, separate from the Digital Library of India collection above). Real yield was small: 98 genuinely new items, ~2.18M words (per the corrected count), most of the reachable range overlapped with content already collected from the Digital Library of India source. Stopped after hitting archive.org's 10,000-result search pagination cap. Not worth relaunching without a fix for that cap. Was missing from `token_tracker.py`'s `SOURCES` list until 2026-08-20 (a real counting bug, fixed the same day) despite being fully collected and cleaned since this entry was written.

- **AIKosh** (`aikosh.indiaai.gov.in`), Assamese Wikipedia Corpus. Genuinely open, CC BY 4.0, no login. Redundant: same content the Wikipedia-dump source above already covers.

Submitted, awaiting approval as of this update. `newsonair.gov.in` above is the live, open version of the same content in the meantime.

- **PIB archive** (`archive.pib.gov.in`). Works, no antibot block, but its language menu is only English, Hindi, and Urdu, plus a mixed "Regional Releases" page. That page's language dropdown does list Assamese as an option, but it is an ASP.NET postback control rather than a plain URL, more complex to script against than the payoff seemed to justify; not chased further.

- **LDC-IL "Gold Standard Assamese Raw Text Corpus".** Real, 10.1M words, government-backed, but gated behind an account and a signed institutional undertaking form. Flagged as a Phase 2/3 candidate, not Phase 1.
- **mC4, Assamese subset.** Unverified size, would need loading the actual HuggingFace config to check. Effort-to-payoff looked low given CC-100's own Assamese slice was already tiny, a known pattern for this language across web-crawl corpora.

- **DIKSHA** (diksha.gov.in), Assam-board (SEBA) Assamese-medium textbooks. - **assamarchive.org** ("Digitizing Assam", about 1.28M claimed pages, the single largest potential source found this session if it worked). Login succeeded once and part of its API was reverse-engineered from the site's own JavaScript, but the content-listing endpoint returned consistent server errors, and the account then received a lockout from the volume of test requests made while investigating. Not pursued further without the user's explicit go-ahead, given the risk of extending the lockout. Worth revisiting if the user confirms their own login still works in a browser.
