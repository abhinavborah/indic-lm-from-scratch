# Assamese Manual-Collection Sources

Source-level tracking (one line per site/document-collection). Per-document
detail (pages, word counts, timestamps) lives in `COLLECTION_LOG.md`.

**Directory layout note:** `raw/{ocr,scrape}/` holds unfiltered extracted text
(OCR-corrected or wikitext-stripped, but no purity filtering). `clean/{ocr,scrape}/`
holds the same content after the line/word purity filter and ৰ/ৱ language-ID
heuristic (course requires both retained, not just clean). This split was
added after OCR and Wikipedia were already fully processed with clean-only
output. Their pre-fix runs were relabeled into `clean/` rather than
reconstructed (`raw/ocr/` stays empty until a new book triggers OCR again),
except Wikipedia, which was cheap to fully rerun locally and now has a
genuine raw+clean pair for all 25,110 articles.

- **`../../docs/assamese/books/` (SCERT/NCERT Assamese-medium textbooks, Class IX-X, 29 PDFs).** OCR complete. 4627/4627 pages processed, 100% via Tesseract `ben` fallback (0 pages had a usable Unicode text layer, confirmed real body text rather than a watermark, just non-Unicode legacy glyph fonts or scanned images throughout). Pre-raw/clean-split output (clean-only) lives in `clean/ocr/<slug>.txt` per book. `raw/ocr/` is empty (see directory layout note above).
- **niyomiyabarta.com.** Assamese news site. Scraping concurrently via `scripts/scraper.py` (sitemap-driven discovery, `<article>` extraction, line/word-level purity filter, ৰ/ৱ language-ID heuristic). 10,458 articles scraped total (approximately 2.80M clean words this source), approximately 39,542 remaining as of the 2026-08-17 batch (`BATCH STOP niyomiyabarta: 1033 new articles this batch (3601s)`). Batched: 2000 articles or 1 hour per run, whichever comes first. This batch hit the time cap, not the article cap. At approximately 1000 articles per hour, the full backlog needs roughly another 40 hourly batches.
- **asomiyapratidin.in.** Assamese news site. Sitemap-driven (`news-sitemap.xml`), `<article>` selector. 137 scraped pre-fix (`clean/scrape/asomiyapratidin.txt`), fully drained for its current sitemap window (0 new on last run). Dual raw and clean writes apply once new articles appear.
- **as.wikipedia.org.** Assamese Wikipedia. A dump counts as manual collection since the preprocessing is done in-house. `scripts/wiki_dump_extract.py` downloads `aswiki-latest-pages-articles.xml.bz2` (approximately 67.5MiB, dumps.wikimedia.org), streams it (never fully decompressed to disk), strips wikitext markup to prose by hand (regex-based: templates and tables handled via iterative innermost-removal for nesting, no external wikitext-parser dependency), then runs the same purity filters as OCR/scrape output. Complete, with a full raw and clean pair: 25,110 articles, `raw/scrape/as_wikipedia.txt` approximately 10.79M words (unfiltered), `clean/scrape/as_wikipedia.txt` approximately 10.30M words (purity-filtered), 0 suspect-language pages excluded. This matches expectation for native-written content.
- **as.wikisource.org.** Assamese Wikisource (proofread public-domain literary and document text). Same dump-based manual logic as Wikipedia. `scripts/wikisource_dump_extract.py` auto-downloads `aswikisource-latest-pages-articles.xml.bz2` (approximately 41.6MiB, dumps.wikimedia.org, correct project name is `aswikisource` not `aswikisourcewiki`) to `raw/wikisource_dump/`, reuses `wiki_dump_extract.py`'s wikitext-to-prose stripping and page-streaming code, and writes `raw/scrape/as_wikisource.txt` / `clean/scrape/as_wikisource.txt`. Added 2026-08-18 to push toward the 500M total after the 100M manual floor was found unreachable with existing sources. Status: not yet run. The first attempt (script auto-download) was interrupted partway through, at 14MB of an expected 43.6MB. The partial file was removed. A manual download is in progress as of 2026-08-18.
- **MWirelabs/assamese-monolingual-corpus (HuggingFace).** Third-party pre-cleaned, pre-deduplicated corpus (IITB-IndicMonoDoc, Samanantar Assamese side, and Assamese poetry/civic texts), 1.61M sentences and 77.4M tokens as claimed by the dataset card, CC BY-SA 4.0 (attribution: MWire Labs, 2025, `https://huggingface.co/datasets/MWirelabs/assamese-monolingual-corpus`). This is a downloaded source, not manual, same bucket as Sangraha, added to close the total 500M gap after the manual floor was found unreachable. Downloaded manually as a CSV (`assamese_monolingual_sentences_final_cleaned.csv`, 1,613,879 rows, matches the dataset card exactly) and converted in place to `raw/mwirelabs/mwirelabs_local.txt` (blank-line-delimited, matching the format `token_tracker.py` expects). Complete: real dedup-aware gain measured at 38,030,017 tokens kept, roughly half of the raw 77.4M claimed size. The gap is consistent with expected overlap with Sangraha via the shared Samanantar source, plus normal purity filtering and exact-duplicate dedup. This addition moved the Assamese total from 154.6M (30.9%) to 192.7M (38.5%) of the 500M target. `jintz0/assamese-monolingual-corpus` on HuggingFace is an identical mirror of this same dataset, not an independent source.
- **xobdo.org.** First online Assamese dictionary (established 2006), wiki-based and community-edited. Treated with the same manual-collection logic as Wikipedia: live-scraped with in-house preprocessing, not a bulk dump. `scripts/xobdo_scrape.py` uses the `/alpha` page, which bakes all 361 alphabetical range pairs into its HTML (`loadWordRange(start, end, langId=2, ...)`), each mapping directly to a clean JSON API (`/2025-web/api/wordsalpha.php`) returning word, part-of-speech, and full definition text, no HTML parsing needed. Complete: 47,972 dictionary entries, `raw/scrape/xobdo.txt` approximately 523K words (unfiltered), `clean/scrape/xobdo.txt` approximately 476K words (purity-filtered), 0 suspect-language ranges excluded. Modest volume as expected for a dictionary compared to Wikipedia-scale, and clean and unambiguously native. Ran in approximately 14 minutes (361 ranges, throttled). Candidate `assamesedictionary.org` (claims 293K+ definitions) was not pursued: lower confidence and less independently verifiable than xobdo, whose own Wikipedia page independently corroborates it.

**Concurrency feasibility check.** Approximately 16 minutes of real concurrent runtime (niyomiyabarta, asomiyapratidin, and live-API Wikipedia scraping) measured combined throughput at approximately 840K words per hour, versus an earlier single-source baseline of approximately 130K words per hour. This is roughly a 6.5x gain from running sources concurrently, confirming concurrency is worth scaling further. niyomiyabarta and asomiyapratidin continue running concurrently now that Wikipedia is dump-based and no longer part of the live thread pool.
